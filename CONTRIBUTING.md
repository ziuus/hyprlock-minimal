## Contributing

Thanks for improving hyprlock-minimal.

### Before opening a pull request

- Open an issue for bugs or new config options.
- Keep changes focused and easy to review.
- Verify the lock screen still renders correctly after your change.

### Local setup

Copy the `hyprlock.conf` to `~/.config/hypr/hyprlock.conf` and reload Hyprland.

### Pull request checklist

- Explain what changed and why.
- Link the related issue.
- Include a screenshot if the visual output changes.
